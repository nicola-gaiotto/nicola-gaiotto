# Hi, I'm Nicola Gaiotto 👋

M.Sc. student in **Autonomous Systems and Intelligent Robots** (EIT Digital double degree) –
University of Bologna → **Aalto University**, specialising in Intelligent Robots and Systems.
B.Sc. in Automation Engineering (University of Bologna), with a thesis on bearing condition monitoring
through vibration analysis.

I'm interested in **robotics, control and autonomous systems**: from modelling and control design
to getting the software to run on real robots and machines.

- 🔭 Currently working with **ROS 2**: bilateral teleoperation between a haptic device and a Franka Panda arm,
  and mobile robots in Gazebo
- 📚 Studying reinforcement learning and vehicle mechatronics at Aalto
- 🤝 Open to **internships** in robotics, control, mechatronics and industrial automation
